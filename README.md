# Job99 ✨

Job99 is a web application that helps students, job seekers, and engineers select and prioritize their top 20 dream companies.

## 🌐 Live Demo

https://syesh.github.io/job99/

## Features

- Browse and search 99+ tech companies.
- Select and rank your top 20 dream companies.
- Rearrange companies using drag-and-drop.
- Add custom companies.
- Track selection progress.
- Copy and share your ranked list.
- Save selections using Local Storage.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- Express.js

## Run Locally

```bash
git clone https://github.com/YOUR-USERNAME/Job99.git
cd Job99
npm install
npm start
```

Open `http://localhost:3000` in your browser.
